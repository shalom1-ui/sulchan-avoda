# שולחן עבודה - ניהול

מערכת ניהול לעסק "שולחן עבודה": שליחת הוראות תחזוקה/ניקיון לעובדים (אתר + שלוחת טלפון בימות המשיח),
דיווחים חזרה, צ'אט פנימי, מוטבים למשכורות לכל סניף, והכנסות/הוצאות עם גרף.

## סטאק

Node.js (http מובנה, בלי Express) + `node:sqlite` (מובנה, אין צורך בהתקנת שום דבר) + frontend וניל JS
(קובץ יחיד, בלי build step) — אותו דפוס בדיוק כמו "הפנקס שלי" של המשתמש. **אפס תלויות חיצוניות** (`npm install` לא באמת מתקין כלום, אבל עדיין מריצים אותו ליצירת `node_modules/` ריק אם צריך).

## הרצה מקומית

```
npm start
```

יעלה שרת בכתובת `http://localhost:3000` (או `PORT` שהוגדר). כניסה ראשונה עם:
- משתמש: `admin1` קוד: `0000`
- משתמש: `admin2` קוד: `0000`

**חשוב מאוד:** תחליפו את הקוד `0000` מיד בהתחברות הראשונה (טאב "משתמשים" → לערוך את הקוד), זה קוד ברירת מחדל לא מאובטח.

## בדיקות

```
npm test
```

## מבנה

- `src/db.js` — מסד נתונים (sqlite) + סכימה + זריעת 13 הסניפים ו-2 חשבונות מנהל.
- `src/routes/*` — API: משתמשים/הרשאות, סניפים, מוטבים, הוראות, דיווחים, צ'אט, התראות, כספים+ייבוא.
- `src/routes/yemot.js` — שלוחת הטלפון "קו שולחן העבודה".
- `public/app.html` — כל הממשק הגרפי (אתר), קובץ יחיד.
- `src/lib/xlsxParser.js` / `csvParser.js` / `pdfParser.js` / `htmlTableParser.js` / `importMapping.js` — הועתקו כמו שהם מ"הפנקס שלי" (מוכחים, נבדקו על קבצי בנק/אשראי אמיתיים).

## הגדרת השלוחה בימות המשיח

1. בממשק הניהול של ימות המשיח, הוסיפו שלוחה חדשה מסוג **API** (type=api) בתוך הקו/מרכזייה הקיימת שלכם. תנו לה שם ברור כמו "קו שולחן העבודה".
2. הגדירו את כתובת ה-API של השלוחה ל: `https://<כתובת-השירות-שלכם>.onrender.com/yemot/instructions`
3. **הערה קולית (אופציונלי, שלב מאוחר יותר):** אם תרצו לאפשר לעובדים להשאיר הערה קולית חופשית, יש ליצור שלוחת הקלטה נפרדת (type=record) שחוזרת אוטומטית לשלוחת ה-API (הגדרת `record_end_goto`), ולהגדיר את מספר השלוחה שלה במשתנה הסביבה `YEMOT_RECORD_EXTENSION` ב-Render. בלי ההגדרה הזו, המערכת פשוט מדלגת על שלב ההערה הקולית.
4. **הקוד לזיהוי בטלפון הוא אותו קוד PIN בן 4 ספרות שנקבע לעובד באתר** (טאב "משתמשים").
   **חשוב:** גם מספר הטלפון של העובד (שדה "טלפון" בטאב "משתמשים") חייב להיות מלא, אחרת המערכת לא תוכל
   לחסום שיחות ממספרים לא-רשומים (ר' הבא). כל עוד אף עובד לא הוזן לו טלפון - הבדיקה לא נאכפת (כדי לא
   לנעול בטעות את כולם החוצה); ברגע שיש טלפון רשום לפחות לעובד אחד, רק מספרים רשומים יתקבלו.
   מי שמתקשר ממספר לא רשום מנותק מיד ובשקט, בלי לשמוע בכלל שהשלוחה הזו קיימת.
5. השיחה הראשונה בפועל היא הבדיקה האמיתית של הפרוטוקול (לא ניתן לבדוק מקומית בלי קו טלפון אמיתי) — אם משהו לא עובד כמצופה, תעדכנו ונתקן.

### בניית תפריט ראשי משותף (אם יש רק מספר טלפון אחד בחשבון, משותף לכמה אפליקציות)

אם הקו כבר משמש אפליקציה אחרת (למשל "הפנקס שלי" בשלוחה 1 ישירות, בלי תפריט) ואין מספר טלפון שני פנוי,
בונים תפריט ראשי **בקוד שלנו** (לא בתחביר ext.ini לא-מאומת של ימות) - ר' `router.post("/yemot/main-menu", ...)`
ב-`src/routes/yemot.js`. זה משתמש רק במנגנונים שכבר הוכחו כעובדים: `read=` (בקשת ספרה) ו-
`id_list_message=...g-/<שלוחה>` (מעבר לשלוחה אחרת - אותו מנגנון בדיוק כמו מעבר לשלוחת הקלטה).

**שלבי ההתקנה (בטוחים - כל שלב הפיך):**
1. **מעתיקים** את התוכן הנוכחי של שלוחה 1 (למשל של "הפנקס שלי") - שומרים אותו בצד כגיבוי.
2. **שלוחה 4** (או כל שלוחה פנויה אחרת): מדביקים בה בדיוק את התוכן שהיה בשלוחה 1 (כלומר "מעבירים דירה" -
   `type=api` / `api_link=<הכתובת המקורית>` / `api_url_post=yes`).
3. **שלוחה 1**: מחליפים את התוכן ל:
   ```
   type=api
   api_link=https://sulchan-avoda.onrender.com/yemot/main-menu
   api_url_post=yes
   ```
4. אם מספרי השלוחות שנבחרו שונים מ-4/3 - מעדכנים את `MAIN_MENU_TARGETS` בתחילת `src/routes/yemot.js`.
5. בודקים בשיחה אמיתית: מתקשרים, אמורים לשמוע "לניהול חשבונות הקישו 1, לשולחן עבודה הקישו 2" ולהיות
   מנותבים בהתאם. **אם משהו לא עובד** - מדביקים חזרה את הגיבוי משלב 1 לתוך שלוחה 1, וחוזרים למצב הקודם מיד.

## שליחת מיילים אמיתיים

באותו דפוס כמו "הפנקס שלי": במצב MOCK (ברירת מחדל) מיילים רק נכתבים ללוג. לשליחה אמיתית, מגדירים ב-Render:
`EMAIL_MOCK=false`, `SENDGRID_API_KEY`, `EMAIL_FROM` (כתובת מאומתת מול SendGrid).

## מה עוד לא בנוי (שלבים הבאים)

- הקלטת הערה קולית אמיתית מהעובד - מוכן בקוד, ממתין לחיבור שלוחת הקלטה אמיתית בימות (ר' למעלה).
- ניהול מוטבים/משכורות מהטלפון (כרגע רק דרך האתר - ניתן להוסיף בהמשך אם צריך).
- עריכה/מחיקה של סניפים ומוטבים מהטלפון.
